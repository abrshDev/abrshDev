## 🧑‍💻 About Me

I'm a freelance full stack developer who enjoys the backend side of things most. I design and build microservices in Go, with a focus on event driven systems, clear service boundaries, and code that is easy to operate in production.

Some of the things I've built and worked on:

* Role based access control (RBAC) systems
* Ledger systems where correctness and auditability matter
* Event driven services using Kafka and gRPC
* Long running workflows with Temporal
* Web frontends and dashboards with Next.js and TypeScript

## 🔭 What I'm Up To

* Going deeper into distributed systems, including a personal project implementing the Raft consensus algorithm in Go
* Reading and applying ideas from Designing Data Intensive Applications
* Learning more about cloud deployment and running services at scale
